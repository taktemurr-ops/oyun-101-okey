# 101 Okey

101 puanla aç, işle, cezayı rakiplere bırak! Yapay zekâ rakiplere karşı; her bölüm kazanılabilir olduğu denetlenmiş bir dağıtım; 100.000 bölüm. Masa Oyunları merkez uygulamasının oyunu; ortak motor: kart-motoru.

Ana ekrandaki **Öğretici** kartı: adım adım dersler, kurallarla denetlenen alıştırmalar ve koçlu alıştırma eli (33 dil).
